## WD-Assignment2

A simple web-based application featuring three interactive tools: a Reverse String utility, a Bill Calculator, and a Palindrome Checker. 
This project demonstrates basic HTML, CSS, and JavaScript skills, created as part of a web development class assignment.

## Features

- **Reverse String**
  - Enter any string and reverse its characters instantly.
- **Bill Calculator**
  - Input a subtotal and tip percentage to calculate the total bill amount (including tip).
- **Palindrome Checker**
  - Enter a number to check if it is a palindrome (reads the same forwards and backwards). Only numeric input is accepted; non-numeric input will prompt an error.
